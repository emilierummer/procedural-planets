# Procedural Planet Generator

This project uses procedural generation to create an explorable universe.

The planets are generated in the same way each run because the randomizer is seeded with their position.

Planet color is affected by temperature. Planet elevation is affected by gravity.

## Controls

- Move the camera with WASD
- Use a mouse or trackpad to zoom in/out
- Click on a planet to see more information on it
